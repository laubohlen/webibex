**Known bug NOT fixed (deliberately, out of scope):**

`return None` instead of `return False` — pinned by
`tests/core/test_b2_utils_moto.py`'s T08 test with an explicit
"do not fix this assertion" comment. Only the unused local variable
(`file_exists = False`, dead code, never read) was removed; the return-value
bug itself is untouched. Flagging here in case this CR's diff on that
function is scanned in isolation without T08's context.

**Why:** explicit user decision this session — build the eventual full
ruleset from `python.md` (not `ALL`, which the project rules reserve for
brand-new projects), but don't let unreviewed auto-fixes touch
below-100%-coverage production code (23-72% coverage in the worst-affected
files: `core/views.py`, `core/signals.py`). Coverage acts as the review
oracle — a fix on a 100%-covered file has the test suite as ground truth; a
fix on a 46%-covered file does not, so the file is deferred until it does.
